# Controls

## Keyboard

| Action | Player 1 | Player 2 |
| --- | --- | --- |
| Up | Up / W | I |
| Down | Down / S | Numpad 5 |
| Left | Left / A | J |
| Right | Right / D | L |
| Shot | Z / J | Numpad 1 |
| Bomb | X / K | Numpad 2 |
| Special | C / L | Numpad 3 |
| Start | 1 / Enter | 2 |
| Coin | 5 | 6 |
| Fullscreen | F11 | — |
| Quit | Esc | — |

## Gamepad (SDL2 Game Controller API)

| Action | Button |
| --- | --- |
| Move | D-pad / left stick |
| Shot | A |
| Bomb | B |
| Special | X |
| Start | Start |
| Coin | Back |

Player 2 gamepad support is not yet mapped; the second player can use the keyboard
mapping above. Steam Deck controls appear as a standard SDL game controller.
