# ESP Ra.De. Native — v0.5.0-pre

Timing and audio-latency repair. These binaries contain **no ROM**; supply your own
`esprade.zip` (World set) with `--rom`, `ESPRADE_ROM`, or the per-user ROM directory.

## What was wrong

1. The SDL loop used `SDL_GetTicks64()` + `SDL_Delay()` and relative deadlines. It could
   oversleep and never recover from busy frames.
2. The YMZ280B was generated at 44.1 kHz, but MAME's chip internal stream is **88.2 kHz**
   (`clock / 192`). Every voice played at half rate and low pitch.
3. The device returned **float32** (`0x8120`) while the port queued **S16** bytes. That
   caused the distorted sound. Audio is now converted with `SDL_AudioStream`.
4. Audio samples were generated from wall-clock time, so slow frames desynchronised sound
   from the game.
5. Layer composition recomputed scroll/flip/row parameters for every pixel.

## What changed

- Absolute high-resolution frame deadline using `SDL_GetPerformanceCounter()` at
  **57.55 Hz** (17.376 ms), hybrid sleep/spin, missed-deadline accounting, no second
  limiter, VSync explicitly disabled.
- YMZ280B mixes at 88.2 kHz and is decimated 2:1 to 44.1 kHz.
- Fractional per-simulated-frame audio accumulation (766/767 samples), independent of wall
  time.
- Device-format conversion, bounded queue (~167 ms max), underrun/overrun counters,
  queue-latency measurement in ms.
- Per-frame and per-scanline hoisting in the layer renderer, precomputed source-x maps and
  a cached palette RGB table.
- `--stats` diagnostics every 300 frames.

## Verified before/after

Fullscreen, 1600x900, Direct3D accelerated, audio enabled:

| Metric | v0.4.0-pre | v0.5.0-pre |
| --- | --- | --- |
| Simulated FPS | 40–56 in busy windows | **57.55 steady** |
| Presented FPS | same as sim | **57.55** |
| p99 frame time | ~100 ms | **~21 ms** |
| Missed deadlines | 105–150 per window | **0** |
| Audio underruns | up to 25 | **0** |
| Audio format | S16 queued into F32 device | **converted S16→device format** |
| YMZ280B rate | 44.1 kHz (half speed) | **88.2 kHz → 44.1 kHz** |
| Queue latency | wall-clock, unbounded growth risk | **~41–63 ms, avg ~52 ms** |

Additional measurements: game+video ~2.2 ms avg, video composition ~2.1 ms avg, SDL
present ~1.1 ms avg, audio mix ~0.02 ms avg.

Regression checks: 600/6,000/60,000 headless frames, hashes
`bc585f53474caa03` / `e9844fb0596e34be` / `3fe0b6dc3322198a`, `bad=0/0`.

## Not verified

- Physical Steam Deck / SteamOS audio device and Gaming Mode.
- Input-matched Stage 1 A/B against MAME. A MAME 0.289 reference AVI/WAV was recorded and
  confirms 57.55 Hz/240x320, but the Lua input script did not reliably reach Stage 1.
- Windowed mode while fully occluded: the desktop compositor can throttle presentation;
  fullscreen and focused-window runs are stable.
- Movement/shot/fullscreen interaction timing on a real desktop session.
