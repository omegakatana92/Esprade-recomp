# ESP Ra.De. Native — v0.6.0-pre

Display-list/VBLANK ordering fix, 90+ second Stage 1 timing capture, and audio-latency
measurements. No ROM included.

## What changed

- **Frame end moved after the VBLANK handler.** `program_frame_wait()` now only raises
  VBLANK and marks a frame pending. `m68k_take_interrupts()` runs the handler, then
  `program_frame_end()` renders, mixes audio, presents and paces. This removes the
  pre-handler render that could capture zero/partial sprite entries.
- Added `--stats` (simulated/presented FPS, p50/p95/p99/max, game/video/present/audio-mix/
  sleep timing, audio queue latency, underruns/overruns, missed deadlines).
- Added deterministic test inputs: `--coin N --start N --autofire --frames N`.

## Display-list verification

- Warning screen, native frame 300 vs MAME 0.289 frame 287: **pixel-identical**
  (mean absolute difference 0.0).
- Stage 1 intro zero sprite entries:
  - MAME frame 1400: **0**
  - native frame 7300: **0**
- The `0x00A890` object animation timer (`subq.b #1,($28,A6)`) translates correctly; the
  divergence was render ordering, not the instruction.

## Timing and audio measurements

12,000-frame deterministic fullscreen run (`--coin 2400 --start 2600 --autofire --frames 12000`,
~208 s), audio enabled, D3D accelerated:

| Metric | Result |
| --- | --- |
| Simulated FPS | **57.55** |
| Presented FPS | **57.55** |
| p50 / p95 / p99 / max | 17.6 / 18.7 / 19.4 / 20.0 ms |
| Missed deadlines | **0** |
| Game logic + video | ~0.9 ms avg |
| Video composition | ~0.9 ms avg |
| SDL present | ~0.8 ms avg |
| Audio mix | ~0.01 ms avg |
| Audio queue latency | **21–45 ms, avg ~34 ms** |
| Underruns / overruns | **0 / 0** |

The 167 ms queue ceiling was never approached (actual queue ~7–16 KB in float32 device
format). A 256-frame device buffer lowered latency but caused startup underruns, so the
512-frame buffer is kept.

Headless regression after ordering: 60,000 frames hash `a61a8f035dcbc528`, `bad=0/0`,
`irq=60000`, `vmiss=0`, 5 frames over budget (max 34.2 ms). 600-frame hash
`0786c2adb4f144df`.

## Not verified

- A human-controlled 90 s Stage 1 run with measured audiovisual offset; the automated
  run reached character select and the Stage 1 intro, but input scripting does not prove
  full player survival.
- Physical Steam Deck/SteamOS audio and Gaming Mode.
- Sample-by-sample audio comparison with MAME/ymfm.
