# ESP Ra.De. Native — v0.4.0-pre

Second tested pre-release: performance/frame-pacing and audio-timing fix on top of
v0.3.0-pre.

These binaries contain **no ROM**. You must own the arcade board or a legally obtained
`esprade.zip` (World set, 13 files). Pass `--rom <path>` or set `ESPRADE_ROM`.

## What changed since v0.3.0-pre

- **Accelerated SDL renderer is now the default** (Direct3D on Windows, OpenGL on Linux),
  with automatic software fallback.
- Software fullscreen was taking 18–37 ms/frame on a 1600x900 desktop, missing the
  17.37 ms arcade budget and starving the fixed-rate audio queue. Accelerated fullscreen
  now holds ~17.5 ms/frame.
- Audio is queued from measured wall-clock time instead of a fixed 766 samples per frame,
  so a late frame no longer slows or stutters the sound.
- Layer pen/colour/category maps are cached until tile RAM or the 8x8/16x16 mode changes.
  Headless core throughput rose from ~189 to ~234 fps.
- Startup now prints the chosen renderer, e.g. `renderer: direct3d (accelerated)`.

## Verified in this build

- ROM verification: 13/13 files by CRC32 + SHA-1.
- 60,000 headless frames with coin at 2400/start at 2600: exit 0, `bad=0/0`,
  hash `3fe0b6dc3322198a`.
- SDL fullscreen accelerated: avg 17.5 ms, present max 13.5 ms.
- SDL gameplay with audio: avg 17.5–17.7 ms, audio queue 4,948–10,376 bytes
  (≈28–59 ms), no underrun.
- Windows exe: warning/title screen and coin/start gameplay verified.
- AppImage: headless 600 frames; windowed AppImage reports `renderer: opengl
  (accelerated)` under Xvfb and stays alive.

## Not yet verified

- Physical Steam Deck (Desktop, Gaming Mode, Steam Input, SteamOS audio).
- Movement, shot/bomb and fullscreen interaction.
- Pixel/sample-exact comparison against MAME.

## Files

`ESPRaDe-Windows-x64.zip`
: Windows x64 executable, headless runner, SDL2.dll, licenses. Unzip next to
  `rom\esprade.zip` or pass `--rom`.

`ESPRaDe-SteamDeck-x86_64.AppImage`
: Linux x86_64 AppImage (glibc 2.35 floor). `chmod +x`, then run. Starts fullscreen;
  `--windowed` overrides. Place the ROM in `~/.local/share/ESPRaDe/rom/esprade.zip` or set
  `ESPRADE_ROM`.
