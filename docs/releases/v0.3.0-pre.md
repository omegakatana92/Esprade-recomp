# ESP Ra.De. Native — v0.3.0-pre

First tested pre-release of the native ESP Ra.De. recompilation.

These binaries contain **no ROM**. You must own the arcade board or a legally obtained
`esprade.zip` (World set, 13 files). Pass `--rom <path>` or set `ESPRADE_ROM`.

## Verified in this build

- ROM verification: 13/13 files by CRC32 + SHA-1 (`esprade` World set).
- Native translation: 0 unsupported instructions; no emulator or 68000 interpreter in the
  binary.
- Windows x64: SDL window opens and renders the warning/title screen.
- Linux x86_64 (Ubuntu 22.04): builds and runs.
- Headless: **60,000 frames** with coin at 2400 and start at 2600, `bad=0/0`, no missing
  translated code, exit 0.
- Identical 60,000-frame hash on Windows and Linux: `3fe0b6dc3322198a`.
- Video: title/attract, in-game street scene, score-ranking screen.
- Audio: YMZ280B 44.1 kHz stereo WAV, non-silent.
- AppImage: produced, headless binary runs from the extracted image; windowed binary
  launches under Xvfb and stays alive.
- Windows SDL coin/start: sent `5` then `1` to the focused window; the game started 1P
  and reached a gameplay scene ("PUSH 2P START").

## Not yet verified

- Physical Steam Deck (Desktop and Gaming Mode), Steam Input, and audio on SteamOS.
- Movement, shot/bomb and fullscreen interaction (coin/start are verified).
- Pixel/sample-exact comparison against MAME.
- Service menu, both-player paths and endings.

## Files

`ESPRaDe-Windows-x64.zip`
: Windows x64 `ESPRaDe-Windows-x64.exe`, `esprade_headless.exe`, SDL2.dll, licenses.
  Unzip next to `rom\esprade.zip` or pass `--rom`.

`ESPRaDe-SteamDeck-x86_64.AppImage`
: Linux x86_64 AppImage (glibc 2.35 floor). `chmod +x`, then run. It starts fullscreen;
  add `--windowed` to override. Place `esprade.zip` in
  `~/.local/share/ESPRaDe/rom/esprade.zip` or set `ESPRADE_ROM`.
